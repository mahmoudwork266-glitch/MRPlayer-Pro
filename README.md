# MR Player — Developed by MAHMOUD RATEB

مشغّل IPTV أصلي (Kotlin + Jetpack Compose + Media3). لا يحتوي على أي قنوات.

## الحصول على ملف APK (الأسهل: GitHub Actions)
1. أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً (New repository).
2. ارفع كل محتويات هذا المجلد (بما فيه المجلد المخفي .github).
3. افتح تبويب Actions ثم Build APK وانتظر 4-6 دقائق.
4. من صفحة التشغيل نزّل Artifact باسم MR-Player-APK ثم فك الضغط لتجد app-debug.apk وثبّته.

## أو عبر Android Studio
File > Open على هذا المجلد ثم Build > Build APK(s).
